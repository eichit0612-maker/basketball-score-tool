# バスケ スコア記録ツール

試合中にタップで記録して、終わったらボックススコアが自動で出るツール。
React + TypeScript + Vite。データはブラウザの localStorage に保存されます（サーバー不要）。

## 使い方

```bash
npm install
npm run dev
```

`http://localhost:5173`（または表示されたポート）を開く。
スマホで使う場合は `npm run dev -- --host` で起動し、同じWi-Fi内の端末から表示されたIPにアクセス。

## 画面

| 画面 | できること |
| --- | --- |
| 試合一覧 | 過去の試合の日付・スコア・状態、新規作成、削除 |
| 試合の設定 | 日付／大会名、クォーター数・分数、両チーム名、選手登録（1人ずつ／まとめて入力） |
| 記録（ライブ） | クォーター・タイマー、選手→プレーの2タップ記録、クォーター別チームファウル（4個でボーナス表示）、シュート成功後のアシスト1タップ入力、交代（コート上）管理、取り消し |
| スタッツ | 選手別ボックススコア、チーム合計、FG%/3P%/FT%、クォーター別得点とチームファウル、得点差の推移グラフ、プレーログ、CSV出力、印刷 |
| シーズン集計 | チーム別の勝敗・平均得失点、選手別の通算／1試合平均、チームごとの試合結果一覧 |

## 記録できるプレー

2P成功/失敗、3P成功/失敗、FT成功/失敗、オフェンスリバウンド、ディフェンスリバウンド、
アシスト、スティール、ブロック、ターンオーバー、ファウル。

選手を選ばずに「チーム」として記録もできます（チームリバウンドや、相手チームの得点だけを追いたいとき）。

## 続けて使うための機能

- **名簿の使い回し** — 設定画面で「この名簿を保存」しておくと、次の試合から選択するだけで選手を読み込めます。
- **バックアップ** — 一覧画面からJSONで書き出し／復元。機種変更やブラウザのデータ削除に備えて。
- **オフライン対応（PWA）** — 一度開けば圏外でも動きます。スマホのブラウザメニューから「ホーム画面に追加」するとアプリのように使えます。

## 仕組み

すべてのプレーを1件ずつイベントとして保存し（`src/types.ts` の `GameEvent`）、
スコアもボックススコアもそこから計算しています（`src/lib/stats.ts`）。
そのため取り消し＝イベント削除だけで、合計値が常に整合します。

```
src/
  pages/Home.tsx      試合一覧
  pages/Setup.tsx     試合・チーム・選手の設定
  pages/Live.tsx      ライブ記録
  pages/BoxScore.tsx  スタッツ表示
  lib/stats.ts        イベント → スタッツ集計
  lib/storage.ts      localStorage 読み書き
  lib/csv.ts          CSV出力
```

## 公開（GitHub Pages）

`main` に push すると GitHub Actions がビルドして Pages に公開します（`.github/workflows/deploy.yml`）。
リポジトリの Settings → Pages → Source を **GitHub Actions** にしておく必要があります。
HashRouter を使っているため、Pages のサブパス配信でも404対策なしで動きます。

## メモ

- データはブラウザごとに保存されるため、別の端末とは共有されません。移行はバックアップ（JSON）で。
- +/-（オンコート得点差）は未対応。
