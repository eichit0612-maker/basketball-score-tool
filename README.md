# バスケ スコア記録ツール

試合中にタップで記録して、終わったらボックススコアが自動で出るツール。
React + TypeScript + Vite。データはブラウザの localStorage に保存されます（サーバー不要）。

## 使い方

```bash
npm install
npm run dev
```

`http://localhost:5173`（または表示されたポート）を開く。
スマホで使う場合は `npm run dev -- --host` で起動し、同じWi-Fi内の端末から表示されたIPにアクセス。

## 画面

| 画面 | できること |
| --- | --- |
| 試合一覧 | 過去の試合の日付・スコア・状態、新規作成、削除 |
| 試合の設定 | 日付／大会名、クォーター数、両チーム名、選手登録（1人ずつ／まとめて入力）、先発の指定 |
| 記録（ライブ） | 選手→プレーの2タップ記録、クォーター切替、選択中の選手のスタッツ即時表示、クォーター別チームファウル（4個でボーナス表示）、途中出場の記録、取り消し |
| スタッツ | 選手別ボックススコア、チーム合計、FG%/3P%/FT%、クォーター別得点とチームファウル、両チームの得点推移グラフ、スコアシート(Excel)出力、CSV出力、印刷 |
| シーズン集計 | チーム別の勝敗・平均得失点、選手別の通算／1試合平均、チームごとの試合結果一覧 |

## 記録できるプレー

**2P成功/失敗、3P成功/失敗、FT成功/失敗、ファウル** の7種類。

一人で記録する前提のため、リバウンドやアシストまで追うと手が回らない。
シュートの成否とファウルだけに絞り、得点・FG%・ファウル数を確実に残すことを優先している。

選手を選ばずに「チーム」として記録もできます（相手チームの得点だけを追いたいときなど）。

スタッツ表の列も **PTS / FG / 3P / FT / F** に固定しています（CSVも同じ）。
過去にリバウンド等を記録した試合でも、その列は表示しません
（データ自体は残っているので、必要になれば列を戻せます）。

## 続けて使うための機能

- **名簿の使い回し** — 設定画面で「この名簿を保存」しておくと、次の試合から選択するだけで選手を読み込めます。
- **バックアップ** — 一覧画面からJSONで書き出し／復元。機種変更やブラウザのデータ削除に備えて。
- **オフライン対応（PWA）** — 一度開けば圏外でも動きます。スマホのブラウザメニューから「ホーム画面に追加」するとアプリのように使えます。

スタッツ画面にプレーの一覧は出しません（記録の訂正は記録画面の「直近のプレー」から）。
1件ずつの記録はCSVに全件入ります。

## 端末について

タブレットやスマホでもURLを開くだけで記録できます（インストール・ログイン不要）。
画面幅に応じて記録画面のレイアウトが変わります。

- 幅600〜1100px（タブレット）: 選手カードを詰めて、16人程度でもスクロールなしで全員表示
- 幅900px以上かつ高さ760px以下（タブレット横向きなど縦が狭い画面）: 選手とプレーボタンを左右に並べ、下部バーの固定を解除
- PC（幅が広く縦にも余裕がある画面）: 従来どおり選手・ボタンを縦に並べる

**データは端末ごとに独立しています**（保存先が各ブラウザのlocalStorageのため）。
別の端末へ移すときは、一覧画面のバックアップでJSONを書き出して読み込んでください。
1つの試合を複数端末で同時に記録して統合することはできません。

## スコアシート出力

スタッツ画面の「スコアシート(Excel)」で .xlsx を書き出せます。2シート構成です。

- **スコアシート**: 試合情報、クォーター別得点とチームファウル、両チームの選手表（先発○／未出場は「欠」）、合計。A4縦・1ページ幅に収まる印刷設定つき
- **ランニングスコア**: 得点が入った順に、Q・チーム・得点者・得点・両チームの累計

Excelの生成ライブラリ（exceljs）はボタンを押したときだけ読み込まれるので、
普段の起動は重くなりません。

## 先発・途中出場・未出場

出場の扱いは3段階です。出場時間は追いません。

- **先発**: 設定画面で「先」を押した選手。5人を超えると注意が出ます（入力はできます）
- **出場**: 記録画面の「出場を記録」をONにして選手をタップ。**コートに出たタイミングで1度押すだけ**で、ベンチに下がっても戻す必要はありません
- **未出場**: 上のどちらでもない選手。記録画面では薄く表示され、スタッツでは最後にまとめて「未出場」と表示されます

記録画面の選手は「先発 → 途中出場 → 未出場」の順に並ぶので、試合が進むほど使う選手が上に集まります。

## 時計を持たない理由

タイマー操作と記録を同時にやると手が足りません。
時計は持たず、**プレーがどのクォーターのものか**だけを記録します。
クォーターの切替は画面上部の `Q1 Q2 Q3 Q4` をタップするだけ（延長は `＋OT`）。

## 仕組み

すべてのプレーを1件ずつイベント（誰が・どのクォーターに・何をしたか）として保存し（`src/types.ts` の `GameEvent`）、
スコアもボックススコアもそこから計算しています（`src/lib/stats.ts`）。
そのため取り消し＝イベント削除だけで、合計値が常に整合します。

```
src/
  pages/Home.tsx      試合一覧
  pages/Setup.tsx     試合・チーム・選手の設定
  pages/Live.tsx      ライブ記録
  pages/BoxScore.tsx  スタッツ表示
  lib/stats.ts        イベント → スタッツ集計
  lib/storage.ts      localStorage 読み書き
  lib/csv.ts          CSV出力
```

## 公開（GitHub Pages）

`main` に push すると GitHub Actions がビルドして Pages に公開します（`.github/workflows/deploy.yml`）。
リポジトリの Settings → Pages → Source を **GitHub Actions** にしておく必要があります。
HashRouter を使っているため、Pages のサブパス配信でも404対策なしで動きます。

## メモ

- データはブラウザごとに保存されるため、別の端末とは共有されません。移行はバックアップ（JSON）で。
- +/-（オンコート得点差）は未対応。
